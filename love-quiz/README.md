# TA 的喜欢，是哪一种型号？｜恋爱型号自测

小红书虚拟商品「恋爱型号测评」的前端站点。纯静态（HTML + 原生 JS），后端是 Supabase。
和疲惫款（仓库根目录那一套）完全独立：不同目录、不同数据表、不同卡密池。

## 目录

| 文件 | 作用 |
|---|---|
| `index.html` | 唯一入口，四个视图都在这里切换 |
| `data.js` | 全部内容：20 道题、TA 的 7 种型号、你的 6 种型号、42 格匹配表 |
| `quiz.js` | 计分：两组维度分别算分 → 比距离定型号 → 查匹配表 |
| `app.js` | 主流程：密码 → 答题 → 三段结果 → 长图 / 分享 / 再拍一份 |
| `poster.js` | 长图渲染（750px 宽，三段式） |
| `admin.html` | 店主后台（卡密、配置、备份） |
| `supa.js` | Supabase RPC 的薄封装 |

## 数据结构

- 前 10 题答「TA 怎么表达」，四个维度：主动 / 明确 / 起伏 / 行动
- 后 10 题答「你自己怎么接收」，三个维度：要确认 / 投入浓度 / 主动表达
- 两组分数分别和型号的特征坐标比欧氏距离，取最近的
- 匹配度来自 7 × 6 = 42 格手写表，不是公式算的

## 两条不能破的线

1. **测的是「你感受到的 TA」**，不是 TA 本人。结果页和长图都必须写这句 —— 否则会被当成「不准」。
2. **不做宣判**。没有「他不爱你」「你们不合适」这类结论，贴合度只表示表达方式咬合得顺不顺，低分写「需要翻译」。
